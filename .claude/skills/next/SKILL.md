1. `docs/internal/STATUS.md`를 읽고 현재 마일스톤과 다음 작업을 확인합니다.
2. 해당 마일스톤 파일을 읽고, "읽을 것"과 그 작업에 직접 필요한 명세만 읽습니다.
3. 작업 하나만 구현합니다. 명세와 어긋나야 하면 멈추고 사용자에게 묻거나 `docs/internal/decisions.md`에 근거를 남깁니다.
4. 작업의 "확인" 명령과 CLAUDE.md의 검증 명령을 실행합니다. 실패하면 고치거나 실패를 그대로 보고합니다.
5. 마일스톤 체크박스와 `docs/internal/STATUS.md`를 갱신합니다.
6. 무엇을 했고, 무엇을 확인했고, 다음 작업이 무엇인지 짧게 보고합니다.
